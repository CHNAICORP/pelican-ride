# Pelican Ride

一个可以直接在浏览器里观看的鹈鹕骑自行车 SVG / HTML 动画。

项目完全由一个自包含的 `index.html` 构成，不依赖框架、构建工具、外部字体或网络资源。打开文件即可播放；也可以把仓库部署到 GitHub Pages、Netlify 或任意静态文件服务器。

## 功能

- 手绘风格的海边场景与鹈鹕骑行插画
- 脚蹼沿踏板轨迹交替运动
- 车轮、辐条、踏板、围巾和身体同步动画
- 鹈鹕眨眼、海浪、云朵与路边景物的细微动效
- 暂停 / 播放、重新出发和速度调节
- 支持 `prefers-reduced-motion`，照顾对动态效果敏感的用户
- 无第三方依赖，双击 `index.html` 即可离线运行

## 本地运行

最简单的方式是直接双击 `index.html`。如果需要通过本地服务器预览：

```bash
python -m http.server 8000
```

然后访问 <http://localhost:8000>。

## 开发说明

这个项目使用原生 HTML、CSS、SVG 和 JavaScript 完成。动画状态由一个纯渲染循环驱动，便于调速、暂停和后续录制。没有使用生成式视频模型；角色、车辆和运动轨迹都在 SVG 中明确绘制和控制，以保持几何结构稳定。

本项目使用 Codex 进行设计、实现与浏览器验证，开发模型为 GPT-6 Astra。视觉与动效方向遵循 Huashu-Design 的动画工作流：优先保证首帧完整、运动连续、控件可用和离线可运行。
